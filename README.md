# 📜 PDF공작소

**1초 만에 끝내는 분할·회전·자르기·합체!**  
서버 전송 없이 웹 브라우저 메모리 안에서만 동작하는 **100% 로컬 보안 PDF 편집기**입니다. 공문서, 영수증, 개인정보가 포함된 민감한 서류도 유출 걱정 없이 안전하게 가공할 수 있습니다.

## ✨ 주요 기능 (Key Features)

* **🔒 완벽한 오프라인 보안 (100% Local Processing)**
  * 외부 서버(API)로 파일을 전송하지 않습니다. 모든 작업은 사용자의 브라우저 내에서 안전하게 처리됩니다.
* **🖼️ 이미지 ➔ PDF 자동 변환**
  * `.jpg`, `.png` 파일을 드래그 앤 드롭하면 즉시 A4 규격의 PDF 페이지로 자동 변환되어 병합됩니다.
* **✂️ 강력한 페이지 조작**
  * **여백 자르기:** 스캔 문서의 지저분한 테두리를 5% 단위로 정밀하게 잘라냅니다.
  * **회전 및 순서 변경:** 페이지별 90도 회전, 좌우 순서 변경, 불필요한 페이지 개별 삭제가 가능합니다.
* **印 투명 직인 / 서명 날인**
  * 배경이 투명한 PNG 도장 이미지를 불러와 원하는 크기(mm)로 문서 위 정확한 위치에 찍을 수 있습니다.
* **🖨️ 실무 맞춤형 출력 옵션**
  * 여러 문서를 병합할 때 **하단 중앙 쪽 번호**를 자동 생성합니다.
  * 대외비, 사본 등 **중앙 대각선 워터마크**를 일괄 삽입합니다.
* **💻 데스크톱 앱(PWA) 완벽 지원**
  * 브라우저 탭을 벗어나 윈도우/맥 바탕화면에 전용 3D 아이콘을 가진 독립된 프로그램처럼 설치할 수 있습니다.

---

## 🛠 기술 스택 (Tech Stack)

* **Frontend:** HTML5, JavaScript (ES6+), CSS3
* **Styling:** Tailwind CSS (CDN)
* **PDF Processing:** 
  * [pdf-lib](https://pdf-lib.js.org/) (문서 생성, 분할, 병합, 이미지 합성)
  * [PDF.js](https://mozilla.github.io/pdf.js/) (문서 렌더링 및 썸네일 미리보기)
* **Architecture:** PWA (Progressive Web App) Ready


### 바탕화면 앱으로 설치하기 (추천)
매번 웹사이트에 접속할 필요 없이 내 컴퓨터에 전용 앱으로 설치해 보세요.
1. Chrome 또는 Edge 브라우저로 위 접속 링크를 엽니다.
2. 브라우저 주소창 우측 끝에 있는 **[ 💻 앱 다운로드(설치) ]** 아이콘을 클릭합니다.
3. 바탕화면에 생성된 'PDF 뚝딱공방' 아이콘을 더블클릭하여 일반 프로그램처럼 쾌적하게 사용합니다.
